# Non-Autoregressive-Transformer

**Training a non-autoregressive model for the machine translation task**

Used the WMT-14 dataset for the task of French to English translation, and tested the model on the test split of the same dataset, obtaining a BLEU score of 12.19

The file `train.py` contains the entire code for training the model with all the hyperparameters defined. For training the model, ensure you have enough GPU for enough time, as the training time would also go in days.
